# Third-party files

The files in `vendor/` are historical BlackBerryFix binaries and archives
provided by a device owner. Their SHA-256 values and external file-history
references are listed in the README. The Windows executable is unsigned. The
original program's source code and license were not included with these
archives, and permission to redistribute them has not been established.

BlackBerryFix and BlackBerry are associated with their respective rights
holders. This independent preservation project is not affiliated with or
endorsed by BlackBerry. The project's MIT license applies only to the
original documentation and verification script; it does not license the
third-party files under `vendor/`. No ownership or open-source status is
claimed for those files.
